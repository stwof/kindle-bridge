# 本地语音合成（TTS）· 可选依赖
#
# 上游项目（MIT 之外，引擎本身用 MPL-2.0）：https://github.com/coqui-ai/TTS
# 这是「朗读」页背后的引擎。它依赖 PyTorch，体积较大，所以**不是**核心依赖，
# 默认不装也能跑其它所有功能。
#
# ⚠️ 重要：Coqui TTS 目前只支持 Python 3.9 ~ 3.11（官方明确不含 3.12+）。
#    本机若是 Python 3.12 / 3.13，请另建一个 3.11 的虚拟环境再装，例如：
#      python3.11 -m venv .venv && .venv\Scripts\activate && pip install -r requirements-tts.txt
#
# 装完重启 Kindle 桥，到「朗读」页即可用；语音模型在首次使用时由 Coqui 自动下载
# （约 50~120 MB，缓存在本机 ~/.local/share/tts，之后不用再下）。
#
# ⚠️ 安装排错：TTS 依赖 aiohttp>=3.8.1、matplotlib>=3.7.0 等。若 pip 报
#    "no matching distributions available for your environment: aiohttp / matplotlib"
#    （常见于镜像源缺包、或镜像只提供需要更新 Python 的包版本，pip 解析器误判），请：
#    ① 先单独装报缺的包，再装本文件：
#        pip install "aiohttp>=3.8.1" "matplotlib>=3.7.0,<3.10"
#        pip install -r requirements-tts.txt
#    ② 若仍装不上，多半是镜像源缺包，临时切官方源（最干净）：
#        pip install --index-url https://pypi.org/simple/ -r requirements-tts.txt
#
# 钉死 0.22.0：这是已在 Windows/3.11 与 Linux/3.10 验证可装的版本，且与
# kindle/tts.py 中针对 PyTorch>=2.6 的 torch.load 补丁匹配。
TTS==0.22.0

# 钉死 setuptools：新版（≥81）已移除 pkg_resources，而 TTS→librosa 的深导入链仍
# `from pkg_resources import resource_filename`。缺失时表现为「TTS 装好了，但一生成就
# 报 ModuleNotFoundError: No module named 'pkg_resources'」（旧代码还会误报“未安装”）。
# 钉到仍含 pkg_resources 的最后一个稳定版，确保深导入可用。
setuptools==69.5.1
